# Naive Bayes Using Python

## About the Project
This project demonstrates Naive Bayes algorithms, a supervised machine learning technique based on Bayes' theorem, used for classification problems.

## Algorithms Covered
- Multinomial Naive Bayes
- Gaussian Naive Bayes
- Bernoulli Naive Bayes

## Concepts Covered
- Introduction to Naive Bayes
- Bayes' Theorem
- Text Classification
- TF-IDF Vectorization
- Model Training
- Prediction
- Model Evaluation

## Applications
1. Spam Message Detection
2. Credit Risk Prediction
3. Heart Disease Classification
4. App Notification Click Prediction

## Datasets
- spam.csv
- CreditRisk.csv
- HeartDisease.csv
- AppNotification.csv

## Evaluation Metrics
- Accuracy Score
- Confusion Matrix
- Precision
- Recall
- F1-Score
- Classification Report

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Jupyter Notebook

## Project Structure
- Naive_Bayes.ipynb
- spam.csv
- CreditRisk.csv
- HeartDisease.csv
- AppNotification.csv
- README.md

## Objective
To understand and implement different Naive Bayes algorithms for solving real-world classification problems using Python.
